# Slate: AI Smart Notebook

Slate is a premium, AI-powered smart notebook application built with Kotlin and Jetpack Compose. It features a Pro Max aesthetic with true Obsidian/Black backgrounds, glassmorphism overlays, and deeply integrated AI Copilot functionalities.

## 🚀 Features
- **Neural Mind Map**: Visually explore the relationships between your notes in a drag-and-drop neural graph.
- **Glassmorphic Editor**: Distraction-free, edge-to-edge note editing with a sleek AI floating toolbar.
- **Voice Dictation & Transcription**: Live AI transcription with glowing waveform visualizations.
- **AI Analytics Dashboard**: Deep insights into your note-taking productivity and AI token usage.
- **Pro Max Aesthetic**: Staggered-fade animations, neon glow highlights, and pill-shaped elements across the UI.

2. Open the project in Android Studio.
3. Build and run on an Android Simulator (API 33+ recommended).
